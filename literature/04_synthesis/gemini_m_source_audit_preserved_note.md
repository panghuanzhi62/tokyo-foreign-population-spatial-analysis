## B. Current DF_M01 MVP status

- The DF_M01-only MVP has already been completed.
- The current empirical interpretation remains unchanged:
  - prior Chinese stock is associated with DF_M01 institutional support infrastructure;
  - DF_M01 support infrastructure does not robustly predict short-term subsequent Chinese
    registered-stock growth;
  - no causal mediation claim.
- This preserved Gemini audit does not change the completed MVP result.

## C. Executive verdict from Gemini

- No source is clearly stronger than DF_M01 for the main MVP M variable.
- DF_M01 remains the strongest reproducible official bulk source.
- CLAIR consultation desks and OTIT supervising organizations were identified as potentially
  valuable complementary sources.
- Gemini recommended building a composite M, but this recommendation should be treated as a
  future extension rather than a blocker for the completed DF_M01-only MVP.

## D. Source candidates

### DF_M01
- Name: 登録支援機関 / Registered Support Organizations
- Provider: Immigration Services Agency of Japan
- Gemini assessment: strongest reproducible official source, but labor-support biased and not
  China-specific.
- Corrected project interpretation: partial_M_component_with_limitations; registered-by /
  observable-by timing; not precise active 2024 stock unless cancellation/deletion status is
  available.

### NEW_M05
- Name: 全国の外国人相談窓口 / Foreign Resident Consultation Desks
- Provider: CLAIR
- URL: https://www.clair.or.jp/tabunka/portal/consultation-offices-nationwide/soudanmadoguchi/
- Gemini assessment: official, national, Excel, migrant-oriented public consultation source.
- Project status: valuable complementary source; requires local validation of fields, address,
  municipality linkage, languages, Chinese marker, and date/status.

### NEW_M06
- Name: 監理団体一覧 / OTIT Supervising Organizations
- Provider: OTIT
- Example URL: https://www.otit.go.jp/upload/docs/260528_3.pdf
- Gemini assessment: official, national, includes receiving-country codes such as CHN, potentially
  China-specific.
- Project status: valuable complementary labor-infrastructure source; may overlap conceptually
  with DF_M01; requires local validation of format, parsability, 2024 compatibility, Greater Tokyo
  coverage, and CHN filtering.

### DF_M02
- Name: 日本語教育機関 / Japanese Language Institutions
- Provider: MEXT
- Gemini assessment: official and relevant but student-visa biased.
- Project status: robustness_component or descriptive_context_only unless full municipality-level
  address and temporal validity are confirmed.

### NEW_M07
- Name: 居住支援法人 / Residential Support Corporations
- Provider: MLIT / prefectures
- Gemini assessment: official but broad vulnerable-housing support source.
- Project status: control_candidate or descriptive_context_only unless a foreign-resident-specific
  subset can be reproducibly identified.

### DF_M03
- Name: 有料職業紹介事業者 / Licensed Employment Placement Offices
- Provider: MHLW
- Gemini assessment: search-only, no reproducible bulk source, no clear migrant marker.
- Project status: exclude / hold.

### DF_M04
- Name: 宅地建物取引業者 / Real Estate Brokers
- Provider: MLIT / prefectures
- Gemini assessment: generic housing-market service registry, not migrant-oriented.
- Project status: exclude from M; possible generic control only, but not currently needed.

### NEW_M08
- Name: 行政書士会員検索 / Administrative Scriveners
- Provider: Gyoseishoshi association
- Gemini assessment: search-only, quasi-official, not reproducible as bulk source.
- Project status: exclude / hold.
