# Topic Selection for Japan and Canada Applications

## Why the project should serve four goals

This project is deliberately structured to serve four long-term goals at once:

1. A Cities-level paper. The academic article is the primary scholarly output
   and anchors credibility for everything else.
2. Japan project researcher / visiting researcher applications. A concrete,
   public-data, Tokyo-focused urban migration study demonstrates fit with
   Japanese host institutions and data environments.
3. Canada migration / urban studies research applications. The settlement,
   housing, services, and vulnerability framing is transferable to Canadian
   urban migration research agendas.
4. A future Chinese-speaking newcomer settlement intelligence database for
   Japan. The same data pipeline and spatial layers can later seed an applied
   settlement-intelligence product.

## Why opportunity-risk mismatch is currently preferred

Opportunity-risk mismatch is currently preferred as a provisional direction
over pure co-ethnic network analysis or pure prediction because:

- Pure co-ethnic network analysis is already occupied by Sun 2026 for Tokyo and
  would invite direct-overlap and novelty problems.
- Pure prediction is methodologically narrow and does not by itself articulate
  a settlement-policy or settlement-environment contribution.
- Opportunity-risk mismatch reframes the question around the lived settlement
  environment (housing, accessibility, services, disaster exposure) and allows
  a Chinese versus non-Chinese foreign-resident comparison that is not the core
  of Sun 2026.

This preference is provisional and remains subject to the gap verification
matrix.

## Why Japan applications should emphasize certain strengths

Japan project researcher / visiting researcher applications should emphasize:

- GIS and spatial analysis capability
- a public-data workflow built on e-Stat, MOJ, Tokyo Metropolitan Government,
  MLIT, and GSI sources
- urban migration governance relevance
- service access, housing, and disaster risk for foreign residents

## Why Canada applications should emphasize certain strengths

Canada migration / urban studies research applications should emphasize:

- transferable migrant settlement infrastructure concepts
- urban inequality
- housing
- services
- vulnerability

## Commercial database framing

The commercial / settlement-intelligence database framing should remain
internal. It should not dominate the academic article, which must stand on its
scholarly contribution alone.
